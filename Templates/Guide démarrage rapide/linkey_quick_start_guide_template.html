Linkey_MAC

Brancher votre clé

Insérez votre clé sur le port TIC du compteur Linky. Attendre que la LED clignote en BLANC.

2

Configurer le Wi-Fi *

Ouvrez l'app Espressif, scannez le QR code ci-contre, puis saisissez vos identifiants Wi-Fi.

3

Configurer MQTT

Créez l'utilisateur ci-contre dans Home Assistant.
